# Authority policy

A knowledge base must clearly distinguish:

- canonical truth (sources of truth)
- interpretation (human-friendly explanations)
- generated views (derived)
- working notes (draft thinking)

## Choosing canonical truth

Canonical truth can be:
- code/config
- data files (recipes, inventories, form definitions)
- enforced contracts/schemas
- pinned external sources with capture rules

## Conflict resolution

If documents conflict with canonical truth:
- update the document, or
- mark it outdated, or
- record a decision explaining the divergence
