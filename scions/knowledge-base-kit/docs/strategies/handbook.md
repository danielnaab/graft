# Strategy: Handbook

A small set of curated pages that tell the story of the system.

## When it works well
- onboarding is important
- you can keep docs updated alongside changes

## Risks
- large docs drift quietly
- over-summarization without sources

## Minimal implementation
- `docs/README.md` (or `docs/index.md`) as the human entrypoint
- a few topic pages (how it works, glossary, how-to)
