# Knowledge organization strategies

Choose a strategy consciously. Evolve only with evidence.

## Strategies

1. [Handbook](handbook.md) — curated docs for onboarding and shared understanding
2. [Atomic notes + maps of content](atomic-notes.md) — idea development and research
3. [Source-first synthesis](source-first-synthesis.md) — high trust and auditability
4. [Metadata + generated views](metadata-and-views.md) — scale and queryability

## How to choose (quick decision aid)

- If onboarding/browsing is primary → [Handbook](handbook.md)
- If exploration dominates → [Atomic notes](atomic-notes.md)
- If trust/auditability is critical → [Source-first synthesis](source-first-synthesis.md)
- If you need queryable structure at scale → [Metadata + views](metadata-and-views.md)

## When to evolve

Evolve only with evidence:

- Navigation pain → add an index/map of content or a generated view
- Trust pain → increase provenance requirements
- Drift pain → strengthen authority boundaries and change-coupling expectations
- Scale pain → introduce minimal metadata and generate views
