# Agent entrypoint (research notes example)

Before making changes, read:
- [Domain knowledge-base.yaml](knowledge-base.yaml)
- [Meta knowledge base](https://github.com/danielnaab/knowledge-base-kit/blob/main/README.md)

Strategy: **Atomic notes + maps** - many small notes, map-of-content index, lifecycle markers.

Rules of thumb:
- Keep individual notes focused on one concept
- Use lifecycle status to indicate note maturity (draft -> working -> stable)
- Update [notes/index.md](notes/index.md) when adding new notes
- Cross-link related notes
