# Weekly planning procedure

## Steps

1. Review the [pantry inventory](../data/pantry.yaml).
2. Choose recipes from [recipes](../data/recipes/beans-and-rice.yaml).
3. Draft a weekly plan note under `notes/`.
4. Generate a shopping list and add it to the weekly plan note.

## Verification

You should be able to answer:
- What meals are planned?
- What ingredients need buying?
- Which sources justify the shopping list?
